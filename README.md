# Abiral Dahal — Portfolio

Minimal, premium portfolio CV with an iOS-developer aesthetic.

- Single-page HTML, no build step
- Three.js wireframe phone in the hero
- EN / ES toggle
- Light / dark theme
- Click-to-copy email
- Downloadable CV (PDF)

## Run locally

Just open `index.html` in a browser. That's it.

## Deploy on GitHub Pages

1. Push this folder to a public repo.
2. Repo → **Settings → Pages** → Source: `main` / root → **Save**.
3. Wait ~30s. Your site lives at `https://<your-user>.github.io/<repo-name>/`.

## Files

- `index.html` — the portfolio
- `Abiral-Dahal-CV.pdf` — downloadable CV
